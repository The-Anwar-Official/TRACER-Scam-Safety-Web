TRACE — Scam Safety & Awareness Platform

Pause the panic. Trace the truth.

TRACE is an interactive web-based scam-awareness platform designed to help people recognize suspicious messages, understand common social-engineering tactics, and make more informed decisions before clicking links, sharing sensitive information, or transferring money.

The project combines an interactive user interface, visual effects, and a message-checking experience to make digital safety more approachable and easier to understand.

🎯 Project Objective

Online scams often rely on urgency, impersonation, fear, and pressure to make people act without verification. TRACE aims to interrupt that process by encouraging users to pause, inspect warning signs, verify information independently, and choose a safer next step.

✨ Key Features

- Interactive Message Checker: Allows users to submit suspicious text messages, emails, or direct messages for an initial check.
- Scam Warning-Sign Awareness: Focuses on common signals such as urgent requests, suspicious links, impersonation language, and requests for money or verification codes.
- TRACE Three-Step Method:
  1. Read the signals.
  2. Verify independently.
  3. Choose your next move.
- Interactive Three-Card Interface: Provides clickable method cards that guide users toward the message-checking section.
- Animated Hero Experience: Includes a visually engaging hero section and a dedicated 3D visual scene.
- Scroll-Based Visual Effects: Uses motion and reveal effects to create a more engaging browsing experience.
- Responsive Layout: Designed to provide a usable experience across desktop and mobile screen sizes.
- Privacy-Conscious Demo Design: The interface is designed around checking a message without requiring an account.
- Educational Transparency: Clearly communicates that automated text checks cannot guarantee whether a message is safe or confirm the identity of its sender.

🧪 Testing & Feedback

During development, the project was tried with approximately 50 college-related accounts, according to the developer's testing experience. The reported feedback was positive, and the website appeared to work well during those trials.

This represents preliminary, informal testing rather than a formal security audit or a statistically validated accuracy study. The number of accounts tested does not, by itself, establish a scam-detection accuracy rate or prove that the platform prevents financial losses.

Further testing can include:

- Testing legitimate and suspicious messages across different scenarios.
- Measuring false positives and false negatives.
- Checking mobile responsiveness and browser compatibility.
- Testing accessibility and keyboard navigation.
- Reviewing privacy behavior and handling of submitted message content.

💰 Potential Value & Savings

TRACE is intended to help users recognize warning signs earlier and make more cautious decisions. Its potential value includes:

- Helping users avoid risky clicks and unverified requests.
- Encouraging verification before sending money or sharing sensitive information.
- Improving awareness of common social-engineering tactics.
- Providing an accessible first step for learning about digital safety.

No verified financial-savings figure is currently claimed. Actual savings would require documented cases showing the amount of loss that was demonstrably prevented. Scam detection and prevention cannot be guaranteed by this educational tool.

🔒 Privacy & Limitations

TRACE is an educational first-pass checking tool, not a replacement for official fraud reporting, financial institution support, or professional cybersecurity analysis.

It may identify common textual warning signs, but:

- It cannot conclusively verify the sender's identity.
- It cannot guarantee that a message is safe or fraudulent.
- Its results depend on the checking logic and the message provided.
- Users should independently verify unexpected payment requests, links, and requests for sensitive information.

Privacy statements should reflect the actual implementation and hosting configuration. Do not submit real passwords, OTPs, banking credentials, or other sensitive personal information for testing.

🚀 Running the Project Locally

Prerequisites

- Node.js
- npm
- Git

Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/TRACE-Scam-Safety.git
cd TRACE-Scam-Safety

Install dependencies:

npm install

Start the development server:

npm run dev

Open "http://localhost:3000" in your browser.

For a production build, run:

npm run build
